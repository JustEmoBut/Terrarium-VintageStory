# Terrarium for Vintage Story

Generates a replica of the real Earth as a Vintage Story world, built from real-world elevation data.
Inspired by [Gegy's Terrarium](https://modrinth.com/mod/terrarium) for Minecraft.

- Real terrain and ocean floors from public elevation tiles, at 10–160 m per block
- Spawn anywhere on Earth by latitude/longitude
- Climate follows latitude: temperature, rainfall, seasons and day length match where you are
- All vanilla worldgen still runs on top: rock strata, caves, soil, ores, vegetation, structures
- `/geotp` to travel to any coordinate or place name, `/geopos` to see where you are

## Requirements

- Vintage Story **1.22** or newer
- An internet connection on the server (or singleplayer host) while new areas are explored. Downloaded tiles are cached on disk.
- The mod is only needed on the server; clients without it can join (they just get vanilla sun angles).

## Installation

1. Download `terrarium_<version>.zip` from the [releases](../../releases) page, or [build it from source](#building-from-source).
2. Put the zip (do not unpack it) into `%APPDATA%\VintagestoryData\Mods` (Linux: `~/.config/VintagestoryData/Mods`).
3. Start the game.

## Creating an Earth world

1. **Singleplayer → Create New World**, pick the **Standard** playstyle (tested).
   The *Creative building* playstyle uses a superflat world type and is not supported.
2. **Customize → Terrarium (Earth)** tab:

| Setting | Default | Notes |
|---|---|---|
| Generate Earth | on | Turn off for a normal vanilla world |
| Spawn latitude / longitude | 41.0082, 28.9784 (Istanbul) | Placed at the world center |
| Horizontal scale | 40 m/block | At 40 m/block the whole Earth fits a 1 million block world |
| Vertical scale | Auto | Exaggerates lowlands, compresses mountains so Everest fits the world height. Linear m/block options cut off high terrain |

All settings apply only when the world is created. Existing worlds without them stay vanilla.

**World height:** with the default 256 blocks relief is fairly flat (the Grand Canyon is about 31 blocks deep). 384–512 gives noticeably deeper valleys and taller mountains at the cost of more worldgen time and disk space.

## Commands

| Command | Description |
|---|---|
| `/geotp <latitude> <longitude>` | Teleport to a real-world coordinate, e.g. `/geotp 27.988 86.925` |
| `/geotp <place name>` | Teleport to a place by name, e.g. `/geotp Grand Canyon` (uses OpenStreetMap Nominatim) |
| `/geopos` | Show your real-world latitude, longitude and elevation |

## Known limitations

- Rainfall is zonal (by latitude only); there is no land cover, biome or soil data yet.
- Land below sea level (Dutch polders, Caspian depression) is filled with sea water.
- Story structures use vanilla placement and may end up in the sea.
- Chunks generated by an older version of the mod are not regenerated, so updates can leave seams in existing worlds.

## Building from source

Requires the .NET 10 SDK and a Vintage Story installation.

```bash
dotnet build -c Release                      # builds and zips into %APPDATA%\VintagestoryData\Mods
dotnet run --project tests/SelfCheck         # assert-based self-check, downloads real tiles (needs internet)
```

The game path defaults to `%USERPROFILE%\Desktop\Vintage Story`. Override it with `-p:VintageStoryPath=...` or the `VINTAGE_STORY` environment variable.
Restart the game after every rebuild; a running game cannot reload the mod assembly.
